# Security

Please report security problems privately, not as a public issue: use **Report a vulnerability** on the [Security tab](https://github.com/pilotofpackets/pingscape/security/advisories/new) of this repository.

Pingscape sends no data to any server and stores nothing except a few settings on the device, so the attack surface is small. Reports about the parsing of system data (routing table, DNS, Bonjour) are especially welcome.
